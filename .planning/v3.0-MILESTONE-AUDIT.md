## 3. Cross-Phase Integration & User Flows

1. **Experience -> Lightbox Traversal:**
   - WebP image assets load instantaneously (17.8MB to 1.41MB reduction).
   - Lightbox transition resets stale image immediately to prevent image flashing.
   - Preloads adjacent photos on demand without memory bloat.
2. **Projects -> Case Study Modal:**
   - Card eyebrows, titles, and descriptions are distinct and effortlessly legible against background screenshots.
   - Clicking any project opens the GSAP origin-aware modal cockpit with 100% scroll isolation.
3. **Education -> Core Competencies:**
   - 4-card vertical stack chassis preserved.
   - Academic Excellence distributes IIT Bombay, CMS, and St. Francis into 3 equal columns (`repeat(3, 1fr)`).
   - High-Stakes Leadership replaces cluttered boxes with bold quantified KPI tags.
   - Stage & Synthesis pill has clean typography without flanking medal icons.
   - Core Competencies matrix eliminates empty card space with 26+ resume proficiencies.
4. **Contact -> Editorial Statement:**
   - Newsreader italic quote starts cleanly with single impactful sentence: *"Building systems that accelerate careers and craft products people genuinely love."*
5. **Mobile Navigation -> Viewport Reflow:**
   - Mobile hamburger drawer links render as tactile command cards with index numerals and directional chevrons.
   - 320px viewport overflow regression resolved via `max-width: 100%` on `.project-card`.
   - Zero horizontal overflow across 1440px, 768px, 375px, and 320px viewports.
