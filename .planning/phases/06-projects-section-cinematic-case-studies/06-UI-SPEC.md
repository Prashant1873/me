## Visuals & Interaction Hierarchy

- **Focal Point:**
  - On Grid: The 16:9 screenshot banner with hover depth (-4px Y lift, 1.03x scale, subtle border glow).
  - In Modal: The 7-column interactive screenshot slideshow in the left cockpit pane.
- **Card Reading Order:**
  1. Screenshot Banner with Monospace Status Pill (`[● 98/98 TESTS]`)
  2. Category Identifier (IBM Plex Mono 12px)
  3. Project Title (Plus Jakarta Sans 20px, Semibold 600)
  4. One-line Narrative Pitch (Plus Jakarta Sans 16px, Regular 400, clamped to 2 lines)
  5. Monospace Tech Stack Pills (`Next.js 16`, `React 19`, `TypeScript`)
  6. Action Row: Direct Link Icon (`↗`) + "Explore Case Study →" trigger
- **Modal Cockpit Reading Order:**
  1. Header: Category Tag + Project Title + Close Button (`✕`)
  2. Left Pane (7 cols): Large 16:9 Viewport + Caption + Filmstrip Thumbnail Strip + Previous/Next chevrons
  3. Right Pane (5 cols): Personal Motivation & Problem Statement → 3 Key Innovations & Proof Grid → Tech Stack Badges → Action CTAs ("Launch Live App ↗" & "View on GitHub ↗")
- **Accessibility:**
  - All icon buttons include explicit `aria-label` (`aria-label="Close case study modal"`, `aria-label="Previous screenshot"`, `aria-label="Next screenshot"`).
  - Keyboard navigation: `ESC` closes modal; `ArrowLeft`/`ArrowRight` traverses screenshots when carousel is focused, or traverses projects when modal navigation is active.
  - Reduced motion: `prefers-reduced-motion: reduce` replaces GSAP zoom springs with instant zero-duration opacity swaps.

## UI Considerations

Applicable state considerations resolved across the Projects Section:

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `#projects-grid` | ✅ covered | Fixed curated sequence renders 6 projects; if filter returns 0, renders documented "No Projects Found in Category" copy |
| loading | `img.project-card__thumb`, `img.modal-slideshow__img` | ✅ covered | Image elements styled with subtle graphite skeleton background pulse until `onload` event completes |
| error | `img.modal-slideshow__img` | ✅ covered | Broken image loads trigger `onerror` and render an inline SVG wireframe placeholder matching the 16:9 aspect ratio |
| overflow | `.project-card__desc`, `.modal-cockpit__body` | ✅ covered | Card descriptions clamped to 2 lines with `-webkit-line-clamp: 2`; modal right pane provides smooth independent vertical scrollbar if content exceeds viewport |
| populated | `#projects-grid` | ✅ covered | Exactly 6 cards rendered in uniform 2x3 CSS grid on desktop, 2-column on tablet (768-1024px), single column on mobile (<768px) |
| long-text | `.project-card__title`, `.modal-cockpit__title` | 🧪 backstop | Bounded by max character lengths in `projects-data.js`; verified via DOM overflow test |
